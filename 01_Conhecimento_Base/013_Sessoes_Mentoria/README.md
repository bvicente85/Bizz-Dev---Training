# Sessões de Mentoria (Knowledge Ingestion)

Esta pasta serve para depositar ficheiros de texto ou PDFs com exportações de conversas tidas com o Gem "Mentor Pragmático" (mobile).

Sempre que adicionar aqui um ficheiro, peça ao Agente Principal para "Processar a nova sessão de mentoria". O agente usará a `Skill_Extrair_Mentoria.md` para extrair os insights e integrá-los na nossa doutrina B2B.
