# Course: Security of AI in Production
**Area:** Artificial Intelligence / Infosec | **Duration:** 7 hours | **Methodology:** A highly technical and practical training, combining security architecture concepts with hands-on labs simulating AI model attacks.

## Description and Objectives
Protect Artificial Intelligence systems, APIs and data pipelines against modern security threats.

* Identify security risks across the AI lifecycle using the MITRE ATLAS framework.
* Detect and prevent adversarial attacks (evasion, extraction, model inversion).
* Secure training and inference pipelines against data poisoning and leakage.
* Setup continuous security monitoring (SOC) based on AI Indicators of Compromise (IoCs).
* Design secure rollback and incident response playbooks under EU AI Act compliance.

## Skills to Develop
* Map AI threat vectors and vulnerabilities using the MITRE ATLAS framework.
* Detect and mitigate adversarial attacks, including prompt injections and data poisoning.
* Implement secure monitoring and incident response playbooks for AI models in production.

## Detailed Syllabus

### SECTION 1: THREAT MODELLING & THE MITRE ATLAS FRAMEWORK
* AI attack vectors: pipeline access, model extraction and data reconnaissance.
* Introduction to the MITRE ATLAS framework and mapping AI vulnerabilities.
* Infrastructure security: dev/train/prod environment isolation and encryption in transit/rest.

### SECTION 2: ADVERSARIAL ATTACKS & TECHNICAL MITIGATION
* Evasion attacks: input manipulation at inference time (prompt injections).
* Integrity attacks: data poisoning and database manipulation.
* Confidentiality threats: model extraction and membership inference (data leakage).
* Implementing defensive distillation and robust training frameworks.

### SECTION 3: AI SECURITY MONITORING & INCIDENT RESPONSE
* Continuous security monitoring: tracking API anomalies and anomalous request patterns.
* SOC integration: alert triggers based on AI-specific Indicators of Compromise (IoCs).
* Incident response playbooks: model containment, rollback and safe re-training validation.

### Practical Exercise
* Conducting a threat modelling session on a production LLM API and configuring defensive guardrails to block prompt injection attacks.

## Trainer Profile / Sales Notes
**Facilitator:** Cybersecurity Analyst and Blue Team Architect specializing in securing API endpoints and model pipelines.
**Sales Pitch:** Essential for security and IT infrastructure teams to prevent AI systems from becoming security liabilities.
