# Curso: Excel Workshop – Extrair e Transformar Dados com Power Query
**Área:** Tecnologias de Informação (Big Data) | **Duração:** 14h (2 dias) | **Metodologia:** Workshop Prático

## Descrição e Objetivos
Explore e liberte o verdadeiro potencial dos seus dados utilizando o Power Query do Excel. Focamo-nos na automação dos processos manuais de preparação e limpeza de dados (processo ETL), garantindo poupança de tempo e minimizando o risco de erros operacionais antes da análise em Excel ou em Power BI.

* Ligar uma folha de cálculo a diferentes fontes de dados externas.
* Transformar e filtrar dados.
* Combinar fontes de dados por fusão ou anexação.
* Rodar ou anular a dinamização de colunas.
* Identificar o editor avançado e a linguagem M.

## Programa Detalhado

### 1. Apresentação do Power Query
* O que é um processo ETL (Extração, Transformação e Carga)?
* Porquê utilizar o Power Query?
* Separador Dados e grupo Obter e Transformar Dados.
* Apresentação da interface do Power Query.
* O conceito de etapas aplicadas.

### 2. Obter Dados de Diferentes Fontes
* Criar consultas a partir de ficheiros externos:
  * Ficheiros planos (TXT, CSV).
  * Ficheiros Excel.
  * Cloud e Web (OneDrive, SharePoint, website).
* Criar uma consulta a partir de uma tabela interna.
* Atualizar os dados.
* Exercícios práticos: Criar consultas diferentes a partir de várias fontes de dados (ERP, base de dados).

### 3. Transformar e Limpar os Dados
* Definir a linha de cabeçalho.
* Verificar e aplicar o tipo de dados correto.
* Selecionar os dados úteis:
  * Selecionar colunas.
  * Manter / Excluir linhas.
  * Filtrar dados.
  * Remover duplicados.
  * Remover erros.
* Substituir valores nulos.
* Dividir / concatenar colunas.
* Transformar colunas:
  * Remover espaços.
  * Limpar.
  * Alterar a capitalização.
* Transformar os dados:
  * A partir de colunas do tipo texto.
  * A partir de colunas do tipo numérico.
  * A partir de colunas cronológicas.

### 4. As Transformações de Destaque
* Rodar uma tabela.
* Anular a dinamização de colunas.
* Exercícios práticos: Criar consultas complexas utilizando ferramentas de transformação de consultas; converter uma tabela de dupla entrada numa lista.

### 5. Adicionar Colunas Calculadas e Agrupar Linhas
* Criar colunas:
  * Personalizada para inserir cálculos.
  * Condicionais.
  * Por exemplo.
  * Índice.
* Agrupamento de linhas:
  * Selecionar as colunas a agrupar.
  * Selecionar os agregados a aplicar.
* Utilizar uma função personalizada.
* Exercícios práticos: Conceber cálculos dentro de consultas para realizar análises estatísticas; utilizar as funcionalidades de cálculo por exemplo para compor um e-mail e um trigrama.

### 6. Combinar Consultas
* Combinar uma consulta por fusão:
  * Escolher o tipo de junção.
* Combinar consultas por anexação:
  * Adicionar uma consulta à folha de cálculo.
  * Compilar todos os ficheiros de uma pasta.
* Duplicar uma consulta.
* Criar uma referência de consulta.

### 7. Descobertas e Boas Práticas
* Dar nomes às etapas.
* Adicionar uma descrição a uma etapa.
* Configurar o ecrã para identificar a qualidade e o perfil da coluna.
* Apresentar a janela de dependências da consulta.
* Compreender o potencial da linguagem M.
* Utilizar o editor avançado.
* Exercícios práticos: Criar consultas combinadas para realizar fusões e anexações, obtendo uma única consulta a partir de múltiplas fontes; calcular a antiguidade.
