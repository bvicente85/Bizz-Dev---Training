# Kibana – Análise e Visualização de Dados

## 1. Visão Geral
A formação Kibana – Análise e Visualização de Dados destina-se a profissionais que procuram explorar e interagir com dados armazenados no Elasticsearch através da interface Kibana. Durante 3 dias, os participantes começam por rever os conceitos fundamentais do ecossistema Elastic, passando à pesquisa avançada através da KQL e ao uso de Data Views. O curso cobre a criação de visualizações personalizadas (Dashboarding e Canvas) para analisar anomalias, dados geoespaciais e séries temporais com o TSVB. A formação também fornece as competências necessárias para trabalhar com Lens e Machine Learning e aprofunda as técnicas de supervisão com o Uptime, capacitando os utilizadores a construir painéis interativos e obter informações valiosas a partir de grandes volumes de dados.

## 2. Objetivos da Formação
- O Kibana é muitas vezes utilizado para pesquisar, visualizar e interagir com os dados armazenados nos índices do Elasticsearch. É frequentemente descrito como "a janela para a pilha elástica". Ao longo da formação os participantes vão:
- Compreender a Pesquisa Básica (Basic Search).
- Procurar dados do Elasticsearch a partir do Kibana (Logs de Erros, Anomalias).
- Construir vários tipos de Visualizações.
- Combinar Visualizações no Dashboard do Kibana.
- Personalizar os dados do Elasticsearch com a criação de gráficos no Kibana.
- Detetar anomalias nos dados com Machine Learning no Kibana.
- Aprofundar as bases de Elastic Cloud, elasticsearch, Beats e Logstash.
