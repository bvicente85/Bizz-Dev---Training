# Microsoft Fabric – Implementação e Administração

## 1. Visão Geral
A formação Microsoft Fabric – Implementação e Administração prepara analistas, engenheiros e cientistas de dados para implementar soluções de engenharia e análise de dados de ponta a ponta na plataforma Microsoft Fabric. Durante 4 dias, os participantes aprendem a usar a cloud centralizada para ingerir, transformar e orquestrar dados com Dataflows Gen2, conectando Real-Time Intelligence com fluxos Eventhouses no Lakehouse. Tendo por base tecnologias de Data Warehouse em estrela e KQL e Spark / tabelas Delta, são dotados de competências de Governança, CI/CD, segurança multicamada, e monitorização para construir arquiteturas escaláveis. O curso é construído num forte equilíbrio de cenários analíticos e pipelines geridos ao longo de uma experiência prática envolvente de uma "solução Cloud-In-A-Box" da inteligência artificial centralizada.

## 2. Objetivos da Formação
- Implementar soluções de engenharia de dados utilizando o Microsoft Fabric.
- Conceber e desenvolver modelos de carregamento de dados eficientes, arquiteturas de dados e processos de orquestração.
- Implementar a ingestão e transformação de dados, bem como a segurança, gestão e monitorização das soluções de engenharia.

## 3. Duração
4 dias

## 4. Programa da Formação

INGERIR DADOS COM O MICROSOFT FABRIC E DATAFLOW GEN2
- Compreender os fluxos de dados Gen2 e integrá-los no Pipeline (ETL no Fabric)

ORQUESTRAR PROCESSOS E A MOVIMENTAÇÃO DE DADOS
- Atividades Copy Data (Copiar) e Execução da Gestão de Erros nos Azure Data Factory

REAL-TIME INTELLIGENCE NO MICROSOFT FABRIC (EVENTSTREAMS E EVENTHOUSE)
- Exploração do Tempo Real – do destino Eventhouse no KQL, e armazenar as visualizações (Dashboards Dinâmicos)
- Monitorização das Informações (Time-series Operations / Dashboards)
- Utilização de vistas Materializadas / Gestão do Data Warehouse em Live Analytics 

IMPLEMENTAR UM LAKEHOUSE E DELTA LAKE (APACHE SPARK / MEDALHÃO)
- A Arquitetura Medalhão  (Bronze / Silver / Gold) – Organização lógica das tabelas Delta
- Analise e Processamento em Notebooks Spark e DataFrames para Analytics

IMPLEMENTAR UM DATA WAREHOUSE NO FABRIC (DW)
- As métricas da infraestrutura e criação dos Relatórios
- Ingestão por T-SQL cruzado entre Modelos Cloud

GERIR, MONITORIZAR, SEGURANÇA E ADMINISTRAÇÃO DO MICROSOFT FABRIC (CI / CD)
- Monitorização Completa - Alertas e Métrica
- Gestão e CI / CD entre os Branch - Azure e DevOps Deployments Lines e WorkSpaces
- Administração RLS Global, Espaços Partilhados e Governance
- Certificação do Data Engineering Platform Fabric - (DP-600 Overview)
