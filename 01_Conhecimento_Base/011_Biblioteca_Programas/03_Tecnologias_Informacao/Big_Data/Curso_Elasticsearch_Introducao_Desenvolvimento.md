# Elasticsearch - Introdução e Desenvolvimento

## Visão Geral
A formação Elasticsearch – Introdução e Desenvolvimento é concebida para programadores, data engineers e administradores de sistemas que planeiam projetar ou desenvolver sistemas corporativos robustos baseados num ecossistema de alto nível na plataforma estrutural Big Data de indexação contínua. Num ambiente NoSQL como o da Elastic Stack, os desafios da manipulação eficiente dos arquivos da infraestrutura com relevância exata e da expansão escalável do seu motor interativo e análise dos índices requer o planeamento e manuseio adequado de clusters nativo em 2 dias com base teórica forte combinada com instalação e manipulação profunda nas estruturas baseadas na análise sintética avançada em Nodes.

## Detalhes
- **Duração:** 2 dias
- **Link URL:** https://www.skolae-formacao.pt/formacao/elasticsearch-introducao-e-desenvolvimento

## Objetivos e Ganhos
O que as equipas alcançam com a formação:
- Compreender plenamente a arquitetura base do sistema orientado ao documento sob o motor principal de pesquisa Big Data NoSQL e a integração das componentes base nativas (Kibana no contexto primário da Elastic Stack interativa no seu centro).
- Modelar de base os documentos corporativos nas bases nativas em ficheiros baseados num mapping das componentes de otimização em index de base corporativo no ecossistema NoSQL com manipulação de CRUD nas REST APIs e agregação na Batch process.
- Executar query pipelines avançadas com algoritmos nativos (paginação avançada, relevance scoring manual base, fuzzy match e tokenizations de base em filtros).
- Manipular a expansão estrutural inicial do seu Sharding, clusters e nós base perante as partições lógicas em expansão em dados massivos para arquitetos ou para processadores pesados da infraestrutura inicial.

## Estrutura do Programa
Os passos da jornada de aprendizagem:

1. **A BASE DOS ECOSSISTEMAS MODERNIZADOS NO-SQL E O ELASTIC STACK**
   O ecossistema Big Data e o CAP theorem perante as exigências corporativas, e as famílias NoSQL gerais interligadas com a Elastic stack base e Kibana de exploração na análise interativa dos ficheiros da estrutura das componentes. A instalação fundamental das partições corporativas para cluster test e exploração fundamental na configuração inicial central.
2. **MODELAÇÃO CRUD NOS DADOS NOSQL (A BASE EXPLORATÓRIA)**
   Uso primário e intensivo das API nativas REST: inserções iterativas unitárias nos arrays e nos index, remoção base global interativa. Inserções massificadas otimizadas à arquitetura do pipeline através da Bulk API nativa base para otimização inicial da equipa corporativa indexando através das pesquisas distribuídas globais. Exemplo Kibana Exploratório da indexação processada em Batch.
3. **PESQUISAS E ALGORITMOS DE TEXTUAL MATCH NOS DOCUMENTOS NATIVOS**
   Consulta nativa interligada: Compreensão teórica e lógica nativa da base da "Relevância do Score Algorítmico". Múltiplas execuções explícitas de ranges temporais e text parsing manual na estrutura final. A análise e Tokening dos dados nativos com Inverted Indexing model. Tokens Filters integrados nativos vs Customizations base dos Analyzers em mappings para casos base com o Mapping Base System nativo da arquitetura principal.
4. **ESCALABILIDADE E ARQUITETURA CLUSTER NATIVA DAS APLICAÇÕES**
   Entender o ecossistema distribuído de alta disponibilidade sob um Cluster test corporativo em Elastic. Master Nodes, Master Status gerido automaticamente, Arquiteturas de partições por Nós primários e réplicas por Node em Sharding (partição horizontal lógica em Shards nos indexes virtuais em nós físicos nativos separados), processamentos práticos dos testes globais avançados na estruturação principal de configuração explícita.
5. **PRÁTICA AVANÇADA DA PESQUISA EXPLORATÓRIA DAS SOLUÇÕES**
   Modelar interativamente as prioridades por "Score Boost" manual no output das queries iterativas, "exclusive filters" de restrição baseada num critério restrito nas consultas globais ou as lógicas nativas em Pagination Rules no API para os frontends nas integrações na stack completa. Boas práticas do processo Big Data nas restrições de arquiteturas nas consultas completas avançadas do cluster master no modelo principal em produção final nativa.
