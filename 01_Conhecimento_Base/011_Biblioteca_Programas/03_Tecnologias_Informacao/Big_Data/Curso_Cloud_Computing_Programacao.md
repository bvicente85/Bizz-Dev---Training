# 01. Cloud Computing – Programação

### 1.1 Perfil do Curso (A Lente do Orgulho)
**(Resumo Executivo para a Equipa Comercial)**
- **Área Temática:** Tecnologias de Informação > Big Data
- **Duração:** 3 dias (21 horas)
- **Público-Alvo:** Profissionais de TI e programadores
- **O Fator "Uau" (A Grande Promessa):** Uma abordagem prática à integração, transformação e normalização de dados em ambiente cloud. Os participantes aprendem a utilizar o Informatica Intelligent Cloud Services (IICS), dominar mapeamentos, fluxos de tarefas, e integração SQL/NoSQL para suportar processos analíticos num centro de informação moderno.

### 1.2 O Programa (A Jornada de Transformação)

**Dia 1 – Introdução e Desenvolvimento de Tarefas**
- Conceitos básicos de integração de dados (Secure Agent, Conectores).
- Configuração de ligações a fontes de dados (SQL, NoSQL, Cloud).
- Desenvolvimento de mapeamentos e utilização de transformações básicas (Filter, Router).

**Dia 2 – Desenvolvimento Avançado e Automatização**
- Gestão de fluxos de tarefas ponta a ponta.
- Introdução a parâmetros e variáveis.
- Gestão de erros, logs e otimização do desempenho dos fluxos (Union, Classifier, Sorter).

**Dia 3 – Manutenção e Depuração**
- Boas práticas de manutenção.
- Gestão de segurança e acessos.
- Exercícios práticos de otimização e depuração completa de fluxos de dados.
