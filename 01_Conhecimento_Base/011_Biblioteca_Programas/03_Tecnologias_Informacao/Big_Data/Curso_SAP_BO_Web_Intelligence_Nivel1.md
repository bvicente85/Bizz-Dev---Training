# SAP BusinessObjects BI 2025 - Web Intelligence - Nível 1

## Visão Geral
A formação SAP BusinessObjects BI 2025 – Web Intelligence – Nível 1 fornece os fundamentos essenciais para explorar e analisar dados empresariais através da interface Web Intelligence. Com um foco fortemente prático, os formandos aprendem a ligar-se a diferentes fontes de dados, projetar consultas eficientes, e criar relatórios, interativos e visualmente ricos. Durante o curso, os participantes vão explorar as funcionalidades core do WebI 2025, incluindo a formatação condicional, a utilização de variáveis e fórmulas complexas, a exportação de dados, bem como as novas capacidades de partilha de conteúdos analíticos no portal da ferramenta, permitindo tomadas de decisão suportadas por dados concretos de forma ágil.

## Detalhes
- **Duração:** 2 dias
- **Link URL:** https://www.skolae-formacao.pt/formacao/sap-businessobjects-bi-2025-web-intelligence-nivel1

## Objetivos e Ganhos
O que as equipas alcançam com a formação:
- Compreender a arquitetura e navegação no BI Launchpad e interface Web Intelligence.
- Criar e modificar consultas utilizando universos, folhas de cálculo e conexões a bases de dados.
- Aplicar filtros lógicos, funções e criar variáveis para enriquecer a informação obtida.
- Formatar relatórios, construir tabelas complexas, aplicar cruzamentos e criar múltiplos tipos de gráficos para visualizar o conhecimento.
- Organizar dados através de agrupamentos, divisões, quebras e ordenações complexas e criar interações profundas entre objetos de relatórios.

## Estrutura do Programa
Os passos da jornada de aprendizagem:

1. **AMBIENTE WEBI**
   Navegação no BI Launchpad 2025 para Web Intelligence, com exploração das preferências dos utilizadores, a navegação entre pastas e categorias e personalização das opções do ambiente Web Intelligence.
2. **CRIAR UM DOCUMENTO WEBI**
   O universo relacional, o painel de criação das consultas, adição e formatação de restrições (filtros estáticos, prompts condicionais dinâmicos). Executar as consultas para apresentação de resultados.
3. **TABELAS**
   Tipos de tabelas disponíveis, criação e modificação, ordenações complexas de dados. Gestão de filtros e formatação gráfica de blocos.
4. **SECÇÕES, GRUPOS E SEPARAÇÕES**
   Criação de agrupamentos, definições de secções para estruturar blocos analíticos, quebras condicionais para organização lógica.
5. **GRÁFICOS E VISUALIZAÇÃO**
   Criação de tipos de dados interativos, personalização gráfica e formatação condicional para realce visual dos insights.
6. **MUDANÇA DO FORNECEDOR DE DADOS DAS TABELAS / GRÁFICOS E FÓRMULAS E VARIÁVEIS**
   Utilização do editor de fórmulas clássico, funções e criação de variáveis contextuais para métricas extra e lógicas de cálculo independentes da base de dados.

## Perfil do Formador (Requisitos)
Facilitador que combina know-how tecnológico em plataformas SAP com experiência em elaboração de reports complexos empresariais e competências pedagógicas para dar resposta a necessidades operacionais e potenciar a aprendizagem em BI/Data Analytics.
