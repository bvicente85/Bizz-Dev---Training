# Governação de Dados / Data Management (DAMA)

## 1. Visão Geral
A formação Governação de Dados / Data Management (DAMA) prepara profissionais para implementar, gerir e otimizar processos de gestão de dados com base na Framework DAMA-DMBOK. Durante 2 dias, os participantes exploram a importância estratégica da governação de dados (DG), aprendem a estruturar modelos operacionais e compreendem os principais desafios e benefícios. A formação abrange temas essenciais do DAMA (DAMA Wheel), incluindo qualidade da informação, arquitetura, design, segurança, MDM e conformidade. Para além disso, foca-se na implementação prática, avaliando a maturidade das organizações e acompanhando a condução da mudança, capacitando os profissionais a maximizar o valor dos dados nas suas empresas.

## 2. Objetivos da Formação
- Adquirir as competências necessárias para definir uma estratégia e implementar a Framework DAMA-DMBOK de governação de dados numa organização.
- Conhecer a fundo a Framework de Gestão de Dados DAMA-DMBOK 2ª edição, que aborda a Arquitetura de Dados, Modelação e Design de Dados, Armazenamento e Operações de Dados, bem como a Integração, Interoperabilidade e Governação de Dados e as principais tendências e desafios nos dados.
