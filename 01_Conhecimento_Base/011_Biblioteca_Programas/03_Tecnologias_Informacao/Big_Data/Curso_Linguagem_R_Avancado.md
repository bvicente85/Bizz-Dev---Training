# Linguagem R – Avançado

## 1. Visão Geral
A formação Linguagem R – Avançado destina-se a utilizadores de R que desejam aperfeiçoar os seus conhecimentos em programação, manipulação complexa de dados e desenvolvimento de aplicações interativas. Durante 2 dias, os participantes aprofundam a programação funcional e a gestão avançada de memória e segurança em R, utilizam packages essenciais (como data.table) para tratar grandes volumes de dados e realizam web scraping (rvest, rselenuim). Adicionalmente, o curso abrange expressões regulares para tratamento de texto, paralelização para melhorar o desempenho e o desenvolvimento e publicação de aplicações web robustas utilizando R Shiny. O curso oferece aos participantes as ferramentas necessárias para resolver problemas complexos com código otimizado e focado em alta performance.

## 2. Objetivos da Formação
- Trabalhar com novos tipos e estruturas de dados.
- Otimizar o seu código R em segurança.
- Recolher informações na Web através da linguagem R.
- Tratar cadeias de caracteres utilizando R.
- Utilizar vários núcleos (do seu PC ou servidor) em R para o tratamento maciço de volumetria de dados.
- Enviar alertas de e-mail automatizados através de scripts em R.
- Criar e publicar uma página em formato de aplicação web estruturada com base num caso de desenvolvimento R através do formato R Shiny.

## 3. Duração
2 dias

## 4. Programa da Formação

Dia 1 – MANHÃ
PROGRAMAÇÃO E DADOS R
- Funções, variáveis e métodos globais vs métodos locais
- Conceito de Ambiente e Closure, gestão de memória
- Controlo e segurança avançados
- Otimização do código e boas práticas de desenvolvimento (tratamento de erros TryCatch)
- Introdução a pacotes para manipular Data.Frames massivos e de alta performance de cálculo, como data.table e dplyr
Exemplos de trabalhos práticos:  
Testes de desempenho de leitura em ambientes globais e gestão de concorrência com Data Table e TryCatch

TRATAMENTO DE DADOS COM EXPRESSÕES REGULARES
- Gestão de strings
- Conhecimento e exploração detalhada de Expressões Regulares em R / Regex
- Pesquisa de correspondência em strings com ou sem RegEx (Grep, Grepl, sub)
Exemplos de trabalhos práticos:  
Exploração de várias estratégias de controlo e validação formal do formato de strings baseada num dataset através da lógica RegEx aplicada a expressões e tratamento funcional

Dia 1 – TARDE
RECOLHA E WEB SCRAPING COM R
- Utilizando rvest, httr para ler e interagir com as páginas da internet, importação e parsing de XML com jsonlite, XLM
- Uso do webdriver / rselenium
Exemplos de trabalhos práticos:  
Automatização da recolha e análise de dados em sites web / Web Scraping

PARALELIZAÇÃO DOS PROCESSOS
- Conhecer os pacotes em R para a extração do processamento
- Utilizar Múltiplos Núcleos / Processadores para execuções da paralelização
- Avaliar os ganhos de cálculo dependendo das famílias P-Apply
Exemplos de trabalhos práticos:  
Teste de alto desempenho multi-core/threads num script para análise volumosa dos ganhos no ambiente local/servidor

Dia 2 – MANHÃ
CONECTAR R A SOLUÇÕES DISTRIBUÍDAS
- Enviar emails via script ou relatório programado dependendo de condições de limiar com alertas

R SHINY - PÁGINAS DASHBOARD E APPs DESKTOP/WEB EM FORMATO R COM INPUT E/OU OUTPUT
- Implementar as secções ui e server com lógica Input, Render, Output
- Funções Reactivas e Observe em R
- Configurar os layouts e estilos usando a lógica Shiny
- Incorporação de lógica HTML e CSS em tags$ para designs Shiny
Exemplos de trabalhos práticos:  
Ajuste da página numa perspetiva de design / CSS sob a interface de User Experience com controlos reativos

Dia 2 – TARDE
- Modularização e escalamento da App num formato multicamada
- Desenvolver a navegação com o pacote Shinydashboard
- Utilizar o pacote Golem para construir a infraestrutura do projeto, garantindo uma aplicação sustentável
Exemplos de trabalhos práticos:  
Transformação da Aplicação Shiny numa Aplicação Distribuída "Multipage" em formato Shinydashboard

- Desenvolvimento guiado por testes com testthat (TDD) e empacotamento para fácil implementação
- Publicação da Aplicação Web e escalamento/escalabilidade
Exemplos de trabalhos práticos:  
Análise de bugs em formato Unit Test em dev
