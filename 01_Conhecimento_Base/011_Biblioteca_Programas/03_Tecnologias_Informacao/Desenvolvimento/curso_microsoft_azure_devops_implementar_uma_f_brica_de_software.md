# Curso: MICROSOFT AZURE DEVOPS - IMPLEMENTAR UMA FÁBRICA DE SOFTWARE
**Área:** Desenvolvimento | **Duração:** 3 dias | **Metodologia:** Presencial / Live Training

## Descrição e Objetivos
Este curso ensina a utilizar o Azure DevOps para criar uma "Fábrica de Software" moderna, automatizando todo o ciclo de vida da aplicação, desde a gestão de tarefas até à entrega contínua.

### Objetivos Pedagógicos:
* Configurar e gerir projetos no Azure DevOps;
* Utilizar Azure Boards para gestão ágil;
* Implementar controlo de versões com Azure Repos;
* Criar e automatizar pipelines CI/CD com Azure Pipelines;
* Gerir pacotes (Artifacts) e planos de teste (Test Plans).

## Programa Detalhado

### 1. Introdução ao Azure DevOps
* Organizações, projetos e permissões;
* Visão geral dos serviços integrados.

### 2. Gestão Ágil com Azure Boards
* Backlogs, Sprints e Quadros Kanban;
* Work Items e rastreabilidade.

### 3. Controlo de Versões com Azure Repos
* Fluxos de trabalho Git (Branching strategies);
* Pull Requests e Code Reviews.

### 4. Integração Contínua (CI)
* Agentes de Build e YAML Pipelines;
* Build de aplicações .NET, Java e Node.js;
* Integração de testes unitários.

### 5. Entrega Contínua (CD)
* Release Pipelines e ambientes;
* Deployment para Azure App Services e Kubernetes;
* Gates de aprovação e estratégias de rollback.

## Perfil do Formador / Notas de Venda
**Formador Especialista:** Especialista em Microsoft Azure e DevOps, certificado Microsoft Certified: DevOps Engineer Expert.
**Argumentos de Venda:** Essencial para equipas que trabalham em ecossistemas Microsoft, integrando perfeitamente o desenvolvimento com a operação na cloud.
