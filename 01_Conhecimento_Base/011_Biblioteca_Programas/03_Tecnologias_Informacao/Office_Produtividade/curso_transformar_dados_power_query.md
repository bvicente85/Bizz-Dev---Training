# Curso: Ateliers Excel – Extrair e Transformar Dados com Power Query
**Área:** Tecnologias de Informação | **Duração:** 14h (2 dias) | **Metodologia:** Ateliers Práticos

## Descrição e Objetivos
Este curso é indicado para utilizadores que desejam automatizar a preparação de fontes de dados para utilização em dashboards e relatórios, garantindo processos mais rápidos, consistentes e eficientes.

**Pré-requisitos:** Ter frequentado a formação "Excel – Consolidar os Conhecimentos Base" ou possuir conhecimentos equivalentes.

* Conectar uma pasta de trabalho a diferentes fontes de dados externas.
* Transformar e filtrar dados.
* Combinar fontes de dados por fusão ou adição.
* Pivotar ou depivotar colunas.
* Identificar o editor avançado e a linguagem M.

## Programa Detalhado

### 1. Apresentação do Power Query
* O que é um ETL (Extract, Transform and Load)?
* Por que usar o Power Query?
* Explorar a guia Dados e o grupo Recuperar e Transformar Dados.
* Apresentação da interface do Power Query.
* O conceito de etapas aplicadas.

### 2. Obter Dados a partir de Diferentes Fontes
* Criar consultas a partir de arquivos externos:
  * Arquivos planos (TXT, CSV).
  * Arquivos Excel.
  * Nuvem e Web (OneDrive, SharePoint, site da internet).
* Criar uma consulta a partir de uma tabela interna.
* Atualizar dados.
* Exercícios práticos: Criar consultas diferentes a partir de várias fontes de dados (ERP, base de dados).

### 3. Transformar e Limpar os Dados
* Definir a linha de cabeçalho.
* Verificar e aplicar o tipo de dado correto.
* Escolher os dados úteis:
  * Escolher as colunas.
  * Manter / excluir linhas.
  * Filtrar dados.
  * Excluir duplicatas.
  * Excluir erros.
* Substituir valores nulos.
* Dividir / concatenar colunas.
* Transformar colunas:
  * Remover espaços.
  * Limpeza.
  * Alterar a caixa de texto.
* Transformar os dados:
  * De colunas do tipo texto.
  * De colunas do tipo numérico.
  * De colunas do tipo cronológico.
* Transformações notáveis:
  * Pivotar uma tabela.
  * Despivotar colunas.
* Exercícios práticos: Criar consultas complexas utilizando ferramentas de transformação de consultas; converter uma tabela de dupla entrada numa lista.

### 4. Adicionar Colunas Calculadas e Agrupar Linhas
* Criar colunas:
  * Personalizadas para inserir cálculos.
  * Condicionais.
  * A partir de exemplos.
  * Adicionar índice.
* Agrupamento de linhas:
  * Escolher as colunas a agrupar.
  * Escolher os agregados a aplicar.
* Utilizar uma função personalizada.

### 5. Combinar Consultas
* Combinar uma consulta por fusão:
  * Escolher o tipo de junção.
* Combinar consultas por adição:
  * Adicionar uma consulta à consulta da pasta de trabalho.
  * Compilar todos os arquivos de uma pasta.
* Duplicar uma consulta.
* Criar uma referência de consulta.

### 6. Descobertas e Melhores Práticas
* Dar nomes aos passos.
* Adicionar uma descrição a uma etapa.
* Configurar a tela para identificar a qualidade e o perfil da coluna.
* Exibir a janela de dependências da consulta.
* Entender o potencial da linguagem M.
* Utilizar o editor avançado.
