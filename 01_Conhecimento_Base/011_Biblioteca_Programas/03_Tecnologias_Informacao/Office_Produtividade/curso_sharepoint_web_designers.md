## 2. Proposta de Valor
A verdadeira Intranet colaborativa num ambiente Microsoft não pode ser monótona ou estática. O SharePoint 365 traz funcionalidades flexíveis de design moderno, que transformam simples repositórios corporativos em autênticos Hubs digitais atrativos com design premium. Este curso capacita criadores e web designers internos para otimizarem graficamente interfaces web e páginas informativas corporativas sem recorrer a longos processos de código.

## 3. Público-Alvo
Qualquer utilizador-admin que pretenda utilizar, editar ou construir uma Intranet sofisticada, portais interativos ou soluções de negócio desenvolvidas com as tecnologias e interfaces Web do SharePoint.

## 4. Objetivos
- Dominar a edição dos templates do SharePoint (Modern Pages versus Classic).
- Estruturar os Hub Sites, Páginas Principais e MasterPages.
- Inserir webparts de multimédia visual ou integração dinâmica de outras listagens.
- Aplicar temas corporativos unificados e esquemas coloridos às Bibliotecas de grupo.
- Criar rotas interativas para o User Experience da Organização.

## 5. Programa
- Layouts modernos e princípios do Design corporativo na Intranet.
- Criação e hierarquização avançada de menus de navegação integrativa para todo o Tenant (Hub Sites).
- Elementos gráficos e Web Parts (Hero, News, Quick Links, Image Galleries).
- Otimização Responsiva: O SharePoint Web no Ecrã Global vs Mobile.
- Permissões de Design, Audiências (Targeting) e versionamento contínuo por Rascunhos.
- Modelagem orgânica com integração HTML, Office UI Fabric, e extensões Framework modernas leves.
