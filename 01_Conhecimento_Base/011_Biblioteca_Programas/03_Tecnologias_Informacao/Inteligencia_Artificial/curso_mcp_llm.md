# Curso: MCP (Model Context Protocol) – Conectar e Controlar Aplicações e Dados a partir de LLM
**Área:** Inteligência Artificial | **Duração:** 7h (1 dia) | **Metodologia:** Técnica / Inovação de Integração

## Descrição e Objetivos
Esta formação prática foca-se no Model Context Protocol (MCP), o novo standard para ligar LLMs a fontes de dados e ferramentas externas com segurança e flexibilidade. Os participantes aprenderão a criar arquiteturas composáveis onde a IA pode ler e escrever em sistemas locais e remotos de forma estruturada.

* Conceber arquiteturas composáveis baseadas em servidores MCP;
* Conectar LLMs a bases de dados, sistemas de ficheiros e ferramentas de DevOps;
* Implementar workflows de IA com respostas adaptadas ao contexto em tempo real;
* Aplicar boas práticas de autenticação e segurança para ambientes de produção.

## Programa Detalhado

### 1. Introdução ao Ecossistema MCP
* Por que utilizar o MCP: Integrações prontas, flexibilidade arquitetural e soberania de dados;
* **Arquitetura MCP:** Hosts, Clientes, Servidores, fontes de dados locais e serviços remotos;
* Exploração de Clientes: Claude Desktop, Fast-agent, Copilot-MCP e integrações com Slack/Jira.

### 2. Protocolo e Implementação Técnica
* **As 3 Camadas do MCP:** Protocolo, Transporte e Mensagens;
* Ciclo de vida de uma ligação MCP e gestão de recursos;
* Utilização de SDKs para disponibilizar ações ao LLM: Python, TypeScript, Java e Kotlin;
* **Laboratório:** Implementação e teste de uma arquitetura MCP com Claude (estudo de código).

### 3. Conectividade e Servidores Standard
* Configuração de servidores para: Filesystem, PostgreSQL, Docker, Kubernetes e GitHub;
* Padronização de trocas com modelos de prompts contextuais;
* **Comportamentos Agênticos:** Otimização via sampling e definição de roots (perímetro do servidor).

### 4. Operações Avançadas e Segurança
* Análise de logs, inspeção, testes e depuração de conexões MCP;
* Monitorização de performance e latência;
* **Segurança de Produção:** Autenticação com OAuth e controlo de acesso a recursos sensíveis;
* **Laboratório:** Construção de uma arquitetura avançada ligando Filesystem e PostgreSQL com otimização de roots.

## Perfil do Formador / Notas de Venda
**Argumentos de Venda:** O MCP resolve o maior problema da IA atual: o isolamento. Este curso é vital para equipas de desenvolvimento que querem que a sua IA não apenas "converse", mas **atue** sobre a infraestrutura (bases de dados, repositórios de código, containers). É a base tecnológica para criar **Agentes de IA reais** que operam dentro das regras da organização.
