# Curso: Microsoft 365 Copilot – Ganhar em Produtividade
**Área:** Inteligência Artificial | **Duração:** 2 dias | **Metodologia:** Form-Ação Prática

## Objetivos da formação
* Analisar o impacto das soluções de IA generativa no ecossistema Microsoft 365.
* Identificar os conceitos de IA responsável, bem como os aspetos globais de segurança e confidencialidade.
* Utilizar prompts predefinidos para interagir eficazmente com o Copilot.
* Identificar as diferenças entre Copilot Chat “free” e Microsoft 365 Copilot.
* Utilizar Microsoft 365 Chat para aceder de forma segura aos dados da empresa.
* Explorar o Microsoft 365 Copilot para melhorar a produtividade através da automatização de tarefas repetitivas, da aceleração da criação de conteúdos e da facilitação da colaboração nas aplicações Microsoft, como Word, Excel, Outlook e Teams.

## Programa da formação

### 1. Introdução
* Compreender o impacto das soluções de IA generativa.
* Situar o papel do Copilot no ecossistema Microsoft 365.
* Compreender os conceitos de IA responsável, segurança e confidencialidade globais.
* Assimilar as diferenças entre Copilot Chat “free” e Microsoft 365 Copilot.
* Compreender o que constitui um “bom” prompt para interagir eficazmente com o Copilot.
* Utilizar prompts predefinidos.
* Incluir os elementos necessários num prompt: objetivo, contexto, fonte e expectativas.
* Conhecer os limites do Copilot.

### 2. Microsoft 365 Chat
* Descobrir o assistente pessoal no Microsoft 365 para aceder de forma segura a todos os dados da empresa.
* Identificar as diferentes formas de acesso ao Copilot Chat.
* Identificar a diferença entre Copilot Chat “trabalho” e Copilot Chat “Web”.
* Identificar assuntos importantes na caixa de correio sem abrir os emails.
* Reunir informações importantes provenientes de várias fontes (Word, Excel, Agenda, Teams).

### 3. Copilot no OneDrive
* Colocar perguntas sobre o conteúdo de um ficheiro sem o abrir.
* Comparar ficheiros.

### 4. Copilot no Word
* Reescrever automaticamente um parágrafo.
* Visualizar conteúdo textual sob a forma de tabela.
* Gerar ideias para o lançamento de um novo projeto, produto ou serviço.
* Redigir um rascunho com Copilot a partir de uma descrição do tema pretendido.
* Gerar novo conteúdo a partir de conteúdo existente.
* Gerar conteúdo no Word a partir de um ficheiro externo.
* Criar um resumo do documento em curso.
* Otimizar o resultado obtido.

### 5. Copilot no Excel
* Analisar, explorar e sintetizar dados rapidamente.
* Analisar resultados a partir de uma lista de dados e identificar automaticamente tendências.
* Criar fórmulas diretamente numa tabela.
* Destacar informações importantes através de formatação condicional e filtros.
* Utilizar Copilot para identificar tendências e criar gráficos previsionais.

### 6. Copilot no Outlook
* Redigir e enviar emails com a ajuda do Copilot.
* Visualizar e copiar o resumo de emails.
* Utilizar o coaching do Copilot para melhorar os emails.
* Planear reuniões a partir de um email com Copilot.

### 7. Copilot no PowerPoint
* Transformar ideias em apresentações impactantes.
* Criar uma apresentação a partir de um ficheiro Word ou PDF.
* Adicionar um diapositivo sobre um tema específico.
* Redigir automaticamente os comentários dos diapositivos.
* Resumir uma apresentação em pontos-chave.

### 8. Copilot no Teams
* Organizar reuniões mais eficazes e acompanhar conversas.
* Estruturar pontos de discussão e resumir ações principais.
* Obter o resumo de uma reunião ou dos pontos abordados.
* Propor ideias de perguntas ainda não colocadas.
* Visualizar simultaneamente a tradução da apresentação do orador.
* Recuperar o atraso numa conversa Teams.
* Ativar notas geradas por IA para visualizar informações‑chave.

### 9. Copilot noutros produtos Microsoft
* Dinamizar a tomada de notas no OneNote com Copilot.
* Explorar elementos de uma página Loop com Copilot.
* Descobrir novas ideias, organizá‑las e resumi‑las no Whiteboard.
* Utilizar Copilot para resumir e pesquisar conteúdos num site SharePoint.
* Gerar automaticamente um formulário ou questionário no Forms.

---
**Nota de Venda:** Foco na segurança de dados empresarial e na utilização prática integrada com o Microsoft Graph. É a solução ideal para empresas que querem passar do "chat básico" para uma produtividade real integrada nos fluxos de trabalho do Office.
