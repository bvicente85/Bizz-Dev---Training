# Curso: Microsoft 365 – Redigir, Analisar e Apresentar Prompts com Microsoft Copilot
**Área:** Inteligência Artificial | **Duração:** 7h | **Metodologia:** Formação Prática

## Descrição e Objetivos
Esta formação destina‑se a utilizadores e responsáveis tecnológicos que pretendem aumentar a produtividade e a qualidade do trabalho diário com IA no ecossistema Microsoft 365.

* Reconhecer as funcionalidades básicas do Microsoft 365 Copilot e as suas capacidades impulsionadas por IA;
* Criar prompts eficazes para assistência de IA no Word, PowerPoint, Excel, Outlook e Teams;
* Melhorar a criação de apresentações utilizando ferramentas orientadas por IA no PowerPoint;
* Melhorar a redação e a edição de documentos com Copilot no Word;
* Otimizar a produtividade das reuniões e a colaboração através do Copilot no Teams;
* Utilizar o Copilot no Excel para análise e visualização de dados;
* Dominar a utilização do Copilot Chat para interação com conteúdos em múltiplas plataformas.

## Programa Detalhado

### 1. Introdução ao Microsoft 365 Copilot
* O que é o Microsoft 365 Copilot;
* Explorar como funciona o Microsoft 365 Copilot;
* Explorar os componentes básicos do Microsoft 365 Copilot;
* Examinar o compromisso da Microsoft com uma IA responsável.

### 2. Criar apresentações eficazes com IA
* Introdução ao Copilot no Microsoft PowerPoint;
* Criar diapositivos envolventes utilizando o Microsoft 365 Copilot no PowerPoint;
* Refinar e melhorar a sua apresentação.

### 3. Redigir documentos impactantes com IA
* Criar conteúdos com Copilot no Microsoft Word;
* Melhorar o seu conteúdo utilizando Copilot no Word.

### 4. Tornar as reuniões mais produtivas com IA
* Desenvolver a colaboração com Copilot nos chats do Teams;
* Ampliar a colaboração com Copilot nas reuniões do Teams.

### 5. Descobrir novos insights de dados com IA
* Simplificar o resumo de dados, a análise e os insights visuais;
* Personalizar a integração, análise e visualização de dados com Copilot no Excel.

### 6. Da caixa de entrada ao impacto: melhorar fluxos de trabalho de email com IA
* Redigir emails envolventes utilizando Copilot no Microsoft Outlook;
* Simplificar a gestão de reuniões utilizando Copilot no Outlook.

### 7. Libertar produtividade e criatividade com o chat orientado por IA
* Compreender o Microsoft 365 Copilot Chat;
* Otimizar o fluxo de trabalho com os dados de trabalho do Copilot Chat;
* Maximizar a produtividade com Copilot Chat baseado na Web.

*Nota: Exemplos de trabalhos práticos são realizados em cada módulo para aplicar as funcionalidades apresentadas.*

## Perfil do Formador / Notas de Venda
**Argumentos de Venda:** Este curso resolve a frustração do "Prompt Vazio". Em vez de comandos genéricos, os participantes saem com uma biblioteca de prompts testados para cada ferramenta do Office 365. É o acelerador de adoção de IA mais prático para quadros administrativos e de gestão.
