# Resolução Criativa de Problemas

## Informação Chave
- **Duração:** Indisponível

## Objetivos
- Aplicar os diferentes métodos de resolução de problemas
- Dominar as ferramentas de resolução de problemas
- Conduzir eficazmente uma reunião de trabalho para a resolução de problemas

## Metodologia
Realização de exercícios práticos para aplicação dos conceitos adquiridos.

## Programa

**IDENTIFICAR E DEFINIR UM PROBLEMA**
- Questões a levantar para definir o que é um problema
- Categorias de problemas – os diferentes tipos de problemas
- Analisar as circunstâncias que podem impedir a correta definição do problema
- Identificar o que pode correr mal numa tomada de decisão
- Delinear uma estratégia de melhoria contínua para encontra uma solução para o problema

**PARTILHA DE EXPERIÊNCIAS: O QUE CADA PARTICIPANTE CONSIDERA UM PROBLEMA NO SEU UNIVERSO PROFISSIONAL**

**ANALISAR INFORMAÇÃO E CAUSAS DOS PROBLEMAS**
- Como recolher informação e receber feedback acerca dos problemas nos processos da empresa
- Analisar comportamentos
- Identificar a causa-raiz

**RESOLVER PROBLEMAS EM GRUPO**
- Realizar uma reunião para resolver problemas
- Estabelecer um debate para gerar ideias
- Controlar as tensões de grupo e utilizar formas de análise de comportamento dos participantes
- Agir com os mais participativos, os passivos e os que perturbam a reunião
- Identificar os critérios e os objetivos de cada participante
- Métodos de procura de soluções para diferentes tipos de problemas – técnicas de criatividade
- Brainstorming – colocar questões, identificar qualidades, promover a participação, fomentar outros pontos de vista
- Desenvolver um mapa mental
- Identificar pontos positivos, negativos e que podem ser interessantes de futuro
- Como lidar com bloqueios à criatividade
- EXERCÍCIO: Simular uma reunião de resolução de problemas e gerir o grupo

**ENCONTRAR SOLUÇÕES E TOMAR DECISÕES**
- Basear as soluções na informação obtida
- Como documentar um processo para resolver problemas
- Encontrar consensos
- Fazer grelhas de decisão
- Construir ferramentas de monitorização
- Definir e estabelecer indicadores de controlo e verificar resultados
- Assumir o risco da tomada de decisão
- EXERCÍCIO PRÁTICO: Decidir sobre uma decisão concreta e implementar soluções
