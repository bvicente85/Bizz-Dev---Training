# Bases de Dados — SKOLAE

Ficheiros de dados, exportações e listas de contactos para apoio à prospeção e desenvolvimento de negócio da SKOLAE.

## 📂 Carteira de Prospeção Ativa (2026-2027)

Estes são os ficheiros principais de trabalho para o ciclo comercial atual:

* **[Accounts 2026-2027.xlsx](./Accounts%202026-2027.xlsx)**: Lista de contas planeadas, targets e objetivos de desenvolvimento de negócio para 2026-2027.
* **[Contacts 2026-2027.xlsx](./Contacts%202026-2027.xlsx)**: Base de dados consolidada de contactos e leads para prospeção ativa durante este ciclo.
